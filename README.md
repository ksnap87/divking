# 👑 DivKing — 배당성장 장기투자 시뮬레이터

안 팔고 보유하면서 **DPS(주당배당)** 가 매년 성장하면, 초기 배당률이 낮아도 시간이 지날수록
**매입원가 대비 실질 배당률(YOC, Yield on Cost)** 이 올라갑니다. 이 웹앱은 그 원리를 연 단위로
시뮬레이션해서 **은퇴 시점의 월배당 목표 달성 여부**를 계산합니다. 백엔드/DB 없이 전부
클라이언트에서 계산합니다.

## 기술 스택

- **React + Vite + TypeScript**
- **Tailwind CSS** (다크 대시보드)
- **recharts** (라인차트)
- 상태 관리는 `useState` 만 사용 (서버/DB 없음)

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 프로덕션 빌드
npm run preview    # 빌드 결과 미리보기
npm run typecheck  # 타입 검사
npm run verify     # 계산 로직 콘솔 검증 (순수 함수 단위)
```

## 입력 파라미터

각 항목은 **슬라이더 + 숫자입력**을 함께 제공합니다.

| 항목 | 기본값 |
|---|---|
| 초기 배당자산 평가금액 | 60,000,000원 |
| 초기 배당수익률 | 3.5% |
| 연 DPS 성장률 | 8% |
| 연 주가 성장률 | 6% |
| 연 추가 적립액 | 12,000,000원 |
| 투자 기간 | 15년 |
| 배당 재투자 | ON |
| 배당 세율 | ISA·연금 0% / 일반계좌 15.4% |
| 월배당 목표액 (세후) | 5,000,000원 |

## 계산 모델 (연 단위 반복)

매년 다음 순서로 진행합니다.

1. **그 해 배당액** = 배당 베이스 × (1 − 세율)  → 세전/세후 모두 기록
2. **평가금액** = 평가금액 × (1 + 주가성장률)
3. **추가 적립액**을 평가금액에 더하고, 적립분의 첫해 배당 기여를 초기수익률로 배당 베이스에 반영
4. **재투자 ON**이면 세후 배당을 평가금액에 더하고 배당 베이스에도 반영(초기수익률 근사)
5. **DPS 성장률**만큼 배당 베이스 증가 (다음 해 대비)
6. 그 해의 평가금액 / 연배당 / 월배당 / YOC 기록

### YOC 두 가지 정의

- **YOC (원가 대비)** = 세전배당 ÷ 누적투자원가 — 핵심 개념 지표. 안 팔고 보유하면 매년 상승.
- **YOC (평가 대비)** = 세전배당 ÷ 평가금액 — 현재 시가 기준 배당수익률.

월배당·연배당 헤드라인 수치는 **세후 실수령** 기준입니다.

### 목표 역산

월배당 목표와 기간을 고정했을 때 필요한 **연 추가 적립액**을 이진탐색으로 역산합니다.
(적립액에 대해 최종 월배당이 단조증가하므로 이진탐색이 성립하며, 결과는 목표를 확실히
넘도록 올림 처리합니다.)

## 시나리오 프리셋

| 프리셋 | 가정 |
|---|---|
| 🛡️ 보수적 | DPS 5% · 주가 4% · 재투자 ON |
| ⚖️ 기본 | DPS 8% · 주가 6% |
| 🚀 공격적 | DPS 10% · 주가 8% |
| 👑 내 실제 포트폴리오 | 배당엔진 5,800만 · 초기수익률 6% · DPS 6% · 주가 5% · 비과세 · 재투자 |

`내 실제 포트폴리오` 프리셋은 배당다우존스 + KB금융 + 커버드콜 2종으로 구성된 배당 엔진
(약 5,800만원 규모)을 근사한 값입니다.

```
scripts/
└─ verify.ts        # 계산 로직 콘솔 검증
```
